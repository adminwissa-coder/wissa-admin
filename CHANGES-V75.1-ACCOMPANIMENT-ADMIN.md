# Wissa Admin V75.1 · Acompañamiento

- Acompañamiento se mueve al módulo `Categorías y precios`, junto a Limpieza y Limpieza exterior.
- Se elimina el editor duplicado de la portada de Configuración.
- Admin puede editar tarifa/hora, mínimo, máximo, longitud del detalle y actividades ES/EN.
- Cada actividad puede activarse/desactivarse y marcarse como `Detalle obligatorio`.
- No se cambian las opciones de preferencia Mujer/Hombre/Sin preferencia para no romper matching existente.
